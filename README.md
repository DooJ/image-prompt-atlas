# 이미지 프롬프트 아틀라스

**[이미지 프롬프트 아틀라스 바로 실행하기](https://dooj.github.io/image-prompt-atlas/)**

실행 주소: https://dooj.github.io/image-prompt-atlas/ — GitHub Pages에서 바로 사용할 수 있습니다.

825개 이미지 생성 사례를 8개 카테고리로 정리한 한국어 정적 페이지입니다.

스타일과 변경할 내용을 편집하고 완성 프롬프트, 빈칸 템플릿 또는 전체 한국어 프롬프트를 복사할 수 있습니다. 원문 예시는 편집 가능한 입력값으로 표시됩니다.

`index.html`을 브라우저에서 열거나 GitHub Pages에서 사용할 수 있습니다. 별도 설치나 빌드가 필요하지 않습니다. 결과 이미지는 인터넷 연결이 필요하며, 입력한 내용은 현재 페이지를 열어 둔 동안 유지됩니다.

## 출처

프롬프트와 예시 이미지는 [EvoLinkAI/awesome-gpt-image-2-API-and-Prompts](https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts)에서 수집했습니다. 각 사례의 원문과 작성자 링크는 페이지에서 확인할 수 있습니다. 한국어 번역과 스타일·내용 분리는 편집을 돕기 위한 것으로 원문 확인이 필요할 수 있습니다. 원본 콘텐츠의 권리는 각 권리자에게 있습니다.
