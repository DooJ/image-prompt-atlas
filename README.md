# 이미지 프롬프트 아틀라스

**[이미지 프롬프트 아틀라스 바로 실행하기](https://dooj.github.io/image-prompt-atlas/)**

실행 주소: https://dooj.github.io/image-prompt-atlas/ — GitHub Pages에서 바로 사용할 수 있습니다.

825개 출처 사례를 검토해 818개 프롬프트로 정리한 한국어 정적 페이지입니다. 8개 카테고리에서 찾아볼 수 있습니다.

제목·키워드로 사례를 찾고 한국어 또는 원문을 편집할 수 있습니다. 각 프롬프트는 **대상·문구**, **구성·장면 설정**, **스타일·조명·화질**로 나뉘며, 각 영역을 조합해도 전체 문장·단계 순서는 유지됩니다. 명시된 아규먼트는 개별 입력칸으로 표시되고 같은 이름의 값은 연결된 모든 위치에 한 번에 반영됩니다.

`index.html`을 브라우저에서 열거나 GitHub Pages에서 사용할 수 있습니다. 별도 설치나 빌드가 필요하지 않습니다. 결과 이미지는 인터넷 연결이 필요하며, 입력한 내용은 현재 페이지를 열어 둔 동안 유지됩니다.

## 편집과 복사

- **아규먼트:** 브랜드명은 회사·서비스·로고 표기, 제품명은 실제 광고 대상 제품·서비스로 구분해 안내합니다. 기본 예시를 수정하면 연결된 모든 위치와 미리보기에 즉시 반영됩니다.
- **대상·문구:** 인물, 사물, 브랜드, 제품, 제목과 문구를 바꿉니다. 아규먼트가 들어갈 본문 위치는 `{{브랜드명}}`, `{{제품명}}`처럼 표시됩니다.
- **구성·장면 설정:** 배경, 요소의 개수와 위치, 레이아웃, 카메라와 화면비를 따로 바꿉니다.
- **스타일·조명·화질:** 화풍, 재질, 색감, 조명, 렌더링 품질과 제외 조건을 따로 바꿉니다.
- **고급 편집:** 세 영역을 원래 순서로 조합한 전체 프롬프트를 직접 편집할 수 있습니다. 원문 순서와 아규먼트 연결을 확인할 때도 사용합니다.
- **빈칸 템플릿:** 명시된 변수만 비웁니다. 나머지 본문은 유지되며, 별도 변수가 없는 사례에는 이 버튼이 나타나지 않습니다.
- **JSON:** 기존 키의 설정값을 세 영역으로 나누며 객체·배열·항목의 순서와 숫자·불린 값을 보존합니다. 새 키는 고급 편집에서 원래 스키마에 맞게 추가할 수 있습니다. 변수에 따옴표나 개행을 넣어도 유효한 JSON으로 복사되며, 문법이 깨지면 수정 전까지 복사를 막습니다.
- **한국어·원문:** 서로 다른 편집본으로 유지합니다. 수정 전 출처 원문은 펼쳐서 대조할 수 있습니다.
- **원문 일부:** 출처 저장소의 본문이 잘리거나 후속 내용이 없는 사례입니다. 완성본으로 오인하지 않도록 표시하고, 공개된 부분만 별도 버튼으로 복사할 수 있습니다. 없는 내용을 만들어 채우지 않습니다.

사례를 선택하면 주소의 끝에 사례 ID가 붙습니다. 예: [시네마틱 치킨 모모스 광고 포스터](https://dooj.github.io/image-prompt-atlas/#ui_case117).

## 중복 사례 정리

- 원문이 같은 7쌍은 하나로 표시합니다. 예시 이미지·출처 기록과 기존 사례 주소는 보존합니다.
- 제목은 같지만 내용이 다른 4묶음의 9개 사례는 이름에 1·2·3을 붙여 구분합니다.
- 판단 근거는 `audit/duplicates.json`, 적용 목록은 `audit/organization.json`에 있습니다.

## 개발 및 검증

Node.js의 내장 모듈만 사용합니다. 별도 패키지 설치는 필요하지 않습니다.

```bash
npm test
npm run build
npm run check
```

- `data/catalog.json`: 전체 사례의 한국어·출처 원문·메타데이터. `original`은 출처를 보존하고, 문법·변수 이름을 교정하거나 무관하게 붙은 요청을 분리한 원문 편집본은 `originalTemplate`에 따로 둡니다.
- `src/template-engine.js`: 변수 해석, 반복 참조 치환, 빈칸 처리, JSON 구조 보존.
- `src/prompt-structure.js`: 프롬프트를 대상·문구, 구성·장면, 스타일·조명·화질 편집 영역으로 나누고 원래 순서로 재조합.
- `src/app.js`, `src/body.html`, `src/atlas.css`: 검색·편집·복사 화면. 사용자 입력은 HTML로 실행하지 않고 텍스트로 표시합니다.
- `scripts/build.cjs`: 데이터와 코드를 압축·내장한 단일 `index.html` 생성. 절대경로의 외부 제작 파일에 의존하지 않습니다.
- `tests/`: 825개 사례 전체의 렌더링과 변수·JSON 회귀 검증.
- `audit/`: 전수 점검 범위와 항목별 교정 근거. 자동 검사는 번역 의미 전체의 완전성을 보증하지 않으므로, 수정 시 해당 원문도 함께 대조합니다.

교정안을 다시 적용할 때는 `node scripts/apply-corrections.cjs`, `node scripts/organize-catalog.cjs`, `npm run build` 순서로 실행합니다. 수정 후 `npm run check`로 검증하고 `index.html`까지 함께 커밋합니다. GitHub Pages는 `main`의 저장소 루트에 있는 배포 파일을 사용합니다.
