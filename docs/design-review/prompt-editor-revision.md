# 프롬프트 편집 구조 개편 검증

## 근거

- 사용자 제공 화면(2026-09-18): 아규먼트 입력과 전체 프롬프트만 보여 구성·스타일·화질을 개별 조합하기 어려웠다.
- `ui_case117`: 브랜드명, 제품명, 주요 제목 문구, 태그라인 문구, 웹사이트의 5개 아규먼트가 있고 구성·장면 및 스타일·화질 조건도 함께 들어 있다.
- 기존 아틀라스 편집기: 스타일과 추가 내용을 분리했지만 의미 단위와 원문 순서를 충분히 보존하지 못했다.

## 결정

모든 프롬프트를 다음 세 영역으로 편집한다.

1. 대상·문구: 아규먼트와 인물·사물·브랜드·제품·텍스트 조건
2. 구성·장면 설정: 배경·배치·개수·카메라·화면비 조건
3. 스타일·조명·화질: 화풍·재질·색감·조명·품질·제외 조건

브랜드명은 회사·서비스·로고 표기, 제품명은 실제 광고 대상 제품·서비스라고 입력 도움말에서 구분한다. 세 영역의 편집값은 원래 프롬프트의 문장 및 JSON 경로 순서로 다시 조합한다. 아규먼트는 `{{브랜드명}}` 같은 읽기 쉬운 표기로 보여 주되, 조합할 때 원본 연결 표식을 복원한다.

## 완료 조건

- 825개 사례의 한국어와 원문 모두 세 편집 영역을 제공한다.
- 편집하지 않은 일반 텍스트는 한 글자도 바뀌지 않고, JSON은 키·계층·배열·값 형식을 보존한다.
- 구성과 스타일을 각각 바꿔도 반복 아규먼트의 이름과 등장 횟수가 유지된다.
- `ui_case117`에서 브랜드명과 제품명이 명확히 구분되고 제품명은 연결된 3곳에 함께 반영된다.
- 데스크톱과 모바일 화면에서 세 영역과 최종 미리보기를 사용할 수 있다.

## 실제 화면 확인

- `ui_case117`: 브랜드 `Boime`은 2곳, 제품 `Digital Signage`는 3곳에 반영됐으며 원본 아규먼트 표식은 완성본에 남지 않았다.
- `ui_case117`: 구성 조건과 스타일 조건을 각각 수정했을 때 두 변경이 모두 원래 위치의 최종 미리보기에 반영됐다.
- `poster_case107`: 구조 영역에서 값을 수정한 뒤에도 전체 프롬프트가 유효한 JSON이었고 복사 가능 상태를 유지했다.
- 390px 뷰포트: 문서 폭과 뷰포트 폭이 모두 390px로 가로 넘침이 없었고, 각 편집 영역은 한 열로 배치됐다.
- 브라우저 콘솔: 오류와 경고가 없었다.
